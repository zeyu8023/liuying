# 流影 · Android 媒体播放器

> **个人自用项目 · 暂不开源 · 随缘更新**
>
> 流影是我为自己的媒体库做的播放器。目前项目源码暂未公开，更新取决于个人需求和空闲时间，没有固定的更新周期。

流影是一款面向自建媒体库的 Android 播放器，支持连接 Emby 和 Jellyfin。在手机或平板上，你可以浏览自己的电影和剧集、在多台媒体服务器间切换，并从上次看到的位置继续播放。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 媒体库 | 支持多服务器切换、跨服务器搜索、收藏、观看历史和继续观看。首页支持「沉浸影院」和「精选发现」两种布局，可调整轮播海报方向和展示的媒体库。 |
| 播放 | 内置 Media3（ExoPlayer）与 mpv，可在播放中保留进度切换内核。支持选集、章节、手势调节亮度与音量、画面缩放、倍速和 Android 画中画。 |
| 字幕与弹幕 | 支持 ASS 特效字幕、SUP 图形字幕和字幕偏移。mpv 支持普通文本双字幕。弹幕可配置来源和显示样式。 |
| 离线与同步 | 支持下载服务器允许下载的电影和剧集。媒体详情可优先播放已下载的文件，支持记录离线进度，并在恢复连接后同步至对应服务器账号。 |
| 片源与圆盘 | 可选择媒体资源版本、音轨和字幕轨。支持兼容的 ISO 圆盘片源，并提供用于选标题和章节的圆盘面板。 |
| 资源中心 | 支持浏览影视资料及演员、显示多平台评分，并可按配置连接 MoviePilot、映迹、影巢等服务。部分功能需要有效的服务地址或 API 密钥。 |
| 外观 | 支持浅色、深色和跟随系统，可选择液态玻璃或高斯模糊、海报取色，独立调节页面和底部导航大小。 |

## 安装与使用

1. 从 [Releases](https://github.com/zeyu8023/liuying/releases) 下载流影 APK。
2. 在 Android 手机或平板上打开 APK。若系统询问，允许本次所用浏览器或文件管理器安装应用。
3. 打开流影，添加你的 Emby 或 Jellyfin 服务器，填写服务器地址及登录信息，然后选择媒体库。

- 系统要求 Android 8.0 或更高版本，支持 ARM64（arm64-v8a）。
- Android 包名为 `app.liuying.mobile`。覆盖安装需要与已安装版本使用相同签名。
- 播放内核、硬解以及 HDR／杜比视界实际输出取决于设备和片源，可在播放信息中查看本次播放的状态。

## 使用反馈

提交问题时请附上流影版本、Android 版本、手机或平板型号，以及复现步骤。遇到播放问题，可一并注明媒体服务器类型、播放内核、文件格式和播放器错误信息。提交前请去掉个人服务器地址、用户名、密码和访问令牌。
